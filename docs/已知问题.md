## 1. 退出 PPSSPP 时 Switch 弹「由于发生错误，软件已关闭」

| 项 | 说明 |
|---|---|
| 严重度 | **次要**（可规避） |
| 影响 | 退出后弹一次错误框，**重新进一次软件即可**，不影响任何功能 |
| 状态 | 未修复 |
| 已有排查基础 | `SDL/SDLMain.cpp` 已埋点：`[exit] __nx_win_exit` 防重入 + `__libnx_exception_handler` |
| 排查线索 | 看日志 `sdmc:/ppsspp_log.txt` 里两组标记：<br>`[exit]`（退出流程走到哪一步）<br>`[mem] svcMapProcessCodeMemory rc=`（JIT 内存映射返回码，与退出崩溃相关） |

## 2. Achievements（成就）不会随游戏切换

从 XMB 启动的游戏，成就集不会切到对应游戏——`Achievements::SetGame()` 仍用 XMB 的路径调用。
不影响游戏运行。

---

## 3. 游戏内 Reset 的行为变化

游戏内 `Reset` 现在会**重启当前游戏**（以前是回到 XMB）。
另外 `__DisplayResetFrameTiming()` 对 XMB 路径是无效代码（遗留）。

## 环境层面的注意（非软件缺陷）

- **构建目录必须在 C 盘 NTFS**，放 exFAT 盘会让 cmake `try_compile` 失败
- **FFmpeg 必须是 57**：用 devkitPro 的 7.x 会导致 PMF 花屏 + 播完卡死
- **本仓库的 `git status` 有陷阱**：`ext/aemu_postoffice` 子模块若损坏，
  `git status` / `git diff` 会 fatal 退出并**静默报「0 改动」**。
  查看真实改动请用 `git diff --ignore-submodules=all`
