# 编译操作手册（不用 AI，手工一步步来）

> 目标：从零复现出本项目的 `PPSSPP.nro`。
> 本手册按"**预防式**"编写——把已踩过的坑直接写进步骤里，照做即可一次编过。
> 想让 AI 代劳请改看仓库根目录的 [`AI-REPLICATE.md`](../AI-REPLICATE.md)。

---

## 0. 先记住三条铁律（违反必踩坑）

| # | 铁律 | 违反的后果 |
|---|---|---|
| 1 | **FFmpeg 必须是 57（libavcodec 57.24.102）**，绝不能用 devkitPro 的 `switch-ffmpeg`（7.x） | PMF 过场动画**花屏**，且**动画播完必定卡死**（画面停、无声音、进程不崩） |
| 2 | **构建目录必须在 C 盘 NTFS** | 放 exFAT 盘（如 F:）会让 cmake 的 `try_compile` 失败 |
| 3 | **所有构建命令必须用 devkitPro 的 msys2 bash** | `cmake` 只装在 devkitPro 的 msys2 里，用系统 Git Bash 会 `command not found` |

还有两条"别手贱"：
- **不要重新生成 `assets/font_atlas.zim/.meta`**（手工重造会**启动即崩**）
- **不要同时开两个构建写同一个构建目录**（会损坏构建目录）

## 2. 第一步：准备 Mesa Switch SDK

Switch 的 Vulkan 来自 Mesa 的 nouveau/NVK 驱动。源码是专门的 Switch 分支：

| 项 | 值 |
|---|---|
| 仓库 | `https://github.com/NaGaa95/mesa-switch.git` |
| 本项目锁定的 commit | `67e632f` |
| 对应 Mesa 版本 | **26.2.2** |

把源码放到 `F:/SWITCH-psp/mesa-switch`（或任意目录），然后用仓库内脚本构建：

```bash
# Docker 不在 PATH 里，先加
export PATH="/c/Program Files/Docker/Docker/resources/bin:$PATH"

# 1) 构建 Docker 镜像（约 5 分钟）
docker build -f C:/switch-build/mesa-ctx/Docker.rust -t devkitpro-mesa-rust C:/switch-build/mesa-ctx

# 2) 容器内构建（约 10 分钟）
MSYS_NO_PATHCONV=1 docker exec mesa-build bash -c "WIPE=1 bash /project/build-unified-docker.sh"
```

> 仓库内已提供脚本：`scripts/switch/deps/build-mesa-sdk-docker.sh`

### 构建后必须做的三件收尾（不做会链接失败）

产物先在 `C:/switch-build/mesa-out/stage/opt/devkitpro/portlibs/switch`，拷到 `C:/switch-build/mesa-sdk`，然后：

1. **补齐 devkitPro 精简安装缺失的库**：把 `libexpat.a`、`libzstd.a`、`libz.a` 放进 `mesa-sdk/lib`
2. **造一个空的 `libelf.a` 桩**：Vulkan/OpenGL 的 cmake 配置要求 libelf，但 Switch 平台实际不需要
3. **用 `aarch64-none-elf-ranlib` 重建所有 `.a` 的符号索引**
   （Mesa 的 `.a` 索引不完整，gcc-ar 的 LLVM14 插件读不了 LLVM23 目标文件 →
   不重建会出现**几千个 `undefined reference`**）

> ⚠️ 构建参数必须是：
> `-Dplatforms=switch -Dvulkan-drivers=nouveau -Dgallium-drivers=nouveau,zink -Doptimization=2`
> **`optimization` 必须是 2**：设为 1 会启用 share-generics，Rust 泛型实例不落地 → 链接失败。

## 3. 第二步：准备 SDL3（必须打补丁）

Switch 的 SDL3 驱动需要两处修改，否则**触屏点不动**、Vulkan 上下文创建失败。

| 补丁 | 作用 |
|---|---|
| Vulkan 外部上下文 | Switch 驱动不调 EGL |
| **触屏修复** | `SDL_SendTouch` 第 5 个参数是**事件类型**不是 bool。原代码传 `true/false` = `type=0/1`，内部 `down = (type == SDL_EVENT_FINGER_DOWN)` 恒为 false → UI 只有高亮、永远不触发点击 |

```bash
cd /f/SWITCH-psp/sdl-src          # SDL3 源码目录
git apply <本仓库>/scripts/switch/deps/sdl3-switch-vulkan-and-touch.patch
# 然后交叉编译安装到 C:/switch-build/sdl-prefix
```

补丁文件：`scripts/switch/deps/sdl3-switch-vulkan-and-touch.patch`

## 4. 第三步：编译 FFmpeg 57（最容易翻车的一步）

**必须自己编译**，源码用 PPSSPP 官方的 ffmpeg 分支：

| 项 | 值 |
|---|---|
| 仓库 | `hrydgard/ppsspp-ffmpeg` |
| commit | `82049cca2e4c1516ed00a77b502a21f91b7843f4` |
| 目标版本 | **libavcodec 57.24.102** |

```bash
bash scripts/switch/deps/build-switch-ffmpeg57.sh      # 约 5 分钟
```

产物前缀：`C:/switch-build/ffmpeg57/prefix`

**务必验证版本**（这步不能省）：

```bash
grep LIBAVCODEC_VERSION_MAJOR C:/switch-build/ffmpeg57/prefix/include/libavcodec/version*.h
```
> 预期：`#define LIBAVCODEC_VERSION_MAJOR  57`
> 若是 **61**（FFmpeg 7.x）→ 用错了，必须换回 57，否则过场动画播完卡死。

## 6. 第五步：编译 NRO

```bash
C:/devkitPro/msys2/usr/bin/bash.exe -lc "bash /f/NSpsp/scripts/switch/build.sh"
```

脚本内置全部 cmake 选项，可用环境变量覆盖：

| 变量 | 默认 |
|---|---|
| `BUILD_DIR` | `/c/switch-build/ppsspp-nx-build2` |
| `MESA_SDK` | `/c/switch-build/mesa-sdk` |
| `FFMPEG_SDK` | `/c/switch-build/ffmpeg57/prefix` |
| `SDL_PREFIX` | `/c/switch-build/sdl-prefix` |
| `JOBS` | `8` |

### 成功的三个判据

1. 末尾输出 `=== 编译完成 ===` 并列出 `PPSSPP.nro`
2. `$BUILD_DIR/PPSSPP.nro` 存在，约 **63–64 MB**
3. 日志里 `error:` 计数为 **0**

> 编译中途**看起来卡住不动、且日志无报错** → 多半是进程被外部杀掉（不是编译错误）。
> 重新执行上面的命令即可**增量续编**（已编好的 `.o` 会保留，不要 clean、不要换目录）。

| 项 | 预期 |

| **插入 UMD Video ISO 并播放** | ✅ 能播放 |

`[mem]`（JIT 内存映射，与退出崩溃相关）、`[exit]`（退出流程）、`[cache]`（着色器缓存）。

## 9. 失败速查表

| 症状 | 原因 | 处理 |
|---|---|---|
| PMF 花屏 + 播完卡死 | FFmpeg 用成 7.x | 重新编译 57，见第 4 步 |
| `cmake: command not found` | 没用 msys2 bash | 用 `C:/devkitPro/msys2/usr/bin/bash.exe -lc` |
| cmake `try_compile` 失败 | 构建目录在 exFAT | 改到 C 盘 NTFS |
| 几千个 `undefined reference` | Mesa `.a` 索引未重建 | `aarch64-none-elf-ranlib` 重建；确认 `optimization=2` |
| 触屏只有高亮、点不动 | SDL3 未打补丁 | 打 `sdl3-switch-vulkan-and-touch.patch` 并重编 SDL3 |
| 启动即崩 | 动了 `assets/font_atlas.*` | 恢复该文件，不要重造图集 |
| `http::HTTPSShutdown()` 未定义 | 缺 `HTTPS_NOT_AVAILABLE ON` | Switch 分支要显式置 ON（脚本已内置） |
| enet 重复符号 | Switch 链了 `aemu_postoffice_server` | 用 `if(NOT USE_LIBNX)` 包住（脚本已内置） |
| 编译"卡住"无报错 | 进程被杀 | 增量续编，不要 clean |

更完整的清单见 [`switch/pitfalls.md`](switch/pitfalls.md)。
